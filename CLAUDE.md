# shelter-mv

Code-rendered music video for "Shelter" (Porter Robinson & Madeon, 2016, 3:37.7).
Claire directs; the renders come from code.

HARD RULE: never write or quote the song's lyrics anywhere, including chat, files,
code, comments and filenames. An API content filter kills any output that contains
them. Key everything to bars and timestamps instead.

## Map
- `Shelter.mp3`: the audio (her copy; never upload or publish it).
- `analysis/`: song analysis. Read `STRUCTURE.md` first (grid, sections, hit
  points). The per-frame audio curves for animation are in `envelopes.npz`
  (30 fps, 6533 frames). Stems are in `stems/` (Demucs htdemucs_ft). Scripts, in
  order: separate.py, beats.py, features.py, vocal.py, sections.py.
- `TREATMENT.md`: the story, the ladder schedule and the section-by-section plan.
  `shots.json` is the shot list, keyed to bars.
- `animatic/`: `make.py` renders `animatic.mp4` (960x540) from shots.json with
  style frames standing in. Rerun it after editing shots.json (takes about 3.5 min).
- `style-frames/`: look development, rounds 1-4.
  - Round 3 decided the inside: pixel for the early phase, faceless low-detail
    humans, Clawd extruded into a 3D solid in 3D worlds, and a fidelity ladder
    (pixel, vector, dimension, luminous, light) shared by Clawd and the
    environments. `10-world-ladder` proves the one-scene, many-lenses method.
  - Round 4 decided the outside world, which keeps ONE style: backlit cut paper,
    with Claude's light shining through it. The style bible is
    `prompts/_paper-common.md`; the reference frames are `11-paper-lab`,
    `12-paper-fusion` and `13-paper-swarm`. `14-pixel-swarm` is the rejected
    baseline.

## Production pipeline (render/GUIDE.md is the handbook for agents)
- `shots/<ID>.js`: one ES module per shot, with `setup(ctx)` and `render(ctx, fr)`. It
  must be a pure function of the frame. `sets/<name>/` holds scene code shared by
  shots, and `lib/` holds helpers (util.js, clawd.js).
- `render/render.mjs`: headless Chrome loads `render/player.html?shot=ID`, which
  renders frames and POSTs raw RGBA to the driver, which pipes it into ffmpeg. The
  driver auto-restarts Chrome at the next frame after a crash or context loss.
  `node render/render.mjs S21 [--still F | --scale 0.5 | --from F --to F]` writes
  `out/shots/S21.mp4`.
- `render/assemble.mjs`:
  - no arguments: `out/film.mp4`, with the song from analysis/shelter.wav, and
    animatic fallbacks for unrendered shots;
  - `--shot ID`: a shot clip with its stretch of the song.
- `render/check_av.py`: verifies audio alignment (measured +0.0 ms).
- `render/sheet.py`: contact sheets. `render/overview.py`: one labelled frame per shot of `out/film.mp4`,
  written to `out/overview.png`. Rerun it after each cut; the short titles are in the script.
- `render/timeline.js` / `core.js`: bars and frames, `T.env` (normalised audio
  curves), `T.events` (beats, kicks, snares, chops, sung, stops). These are
  generated by `render/export_env.py`.
- `shots.json` `shift0`/`shift1` move cuts off the downbeat: S21 starts one beat
  early, so the reactor is dark before the bar-57 kick.
- Node is at C:/Program Files/nodejs (`export PATH="/c/Program Files/nodejs:$PATH"`).
  About 0.15 s per 1080p frame of overhead, plus page time.

## Environment
- Python for the audio work: `.venv/Scripts/python.exe` (torch CPU, librosa,
  demucs, beat_this). System `python3` handles the image work. Node v24 is at
  C:/Program Files/nodejs. Renders go through headless Chrome (see
  style-frames/BRIEF.md).
- Headless Chrome: add `--use-angle=vulkan`. The default D3D11 backend took about
  3 minutes to compile the swarm's shaders, versus about 2 s with Vulkan.
- Grid: 100 BPM, bar 2.4 s = 72 frames, bar b starts at 0.38 + 2.4(b-1) s.
